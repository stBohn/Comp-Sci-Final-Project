Cookie Clicker Game

A idle clicker made in java. Goal is to get as many cookies as you can, click the cookie, buy upgrades, and get more cookies.

How to run:
Clone the repo
Open in vsCode
run "Runner.java"

Features:
Unique pictures
Fun upgrades 
Game saving

Build with:
openjdk 26.0.1
javax.swing, java.awt, and java.io

What I learned:
How object oreinted programming ties into game development, especially the usefulness of inheritance for the buttons. Saving game state logic, General game loop logic, and how to incorperate game art with simple swing tools. Also gained expirence with using Git for version control.
